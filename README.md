# Nexo

Nexo es una plataforma web diseñada para conectar personas que necesitan un servicio con profesionales o estudiantes capacitados para realizarlo. La aplicación permite publicar necesidades, visualizar oportunidades disponibles y destacar a los postulantes mejor calificados, facilitando el proceso de encontrar la persona adecuada para cada trabajo.

El proyecto fue desarrollado como parte de un Proyecto Integrador de Ingeniería en Sistemas y está enfocado en la aplicación de buenas prácticas de desarrollo web, utilizando HTML5 semántico, CSS3 con diseño responsive (Mobile First), Flexbox, CSS Grid y la metodología BEM para la organización de estilos.

## Características

- Diseño responsive adaptable a dispositivos móviles y computadoras.
- Estructura semántica con HTML5.
- Navegación sencilla e intuitiva.
- Sección de necesidades publicadas.
- Sección de postulantes destacados.
- Organización del código CSS mediante variables y metodología BEM.

## Tecnologías utilizadas

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Design (Mobile First)
- Metodología BEM
